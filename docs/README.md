## 文档治理

- 所有新 Codex 窗口先读根目录 `AGENTS.md` 和本目录 `项目总控.md`；未复述当前
  Gate、唯一任务与禁止事项前不得修改文件或调用外部服务。
- 业务核心需求变更：先更新业务核心 PRD，再同步实现、架构、原型和验收文档。
- 渠道能力变更：先更新渠道接入中心 PRD，再同步实现、架构和验收文档；不得绕过接入中心在业务核心中直连平台 API。
- 后续能力先更新路线图；阶段获准启动后，再建立该阶段的正式 PRD、实现、架构和验收文档。
- P0 不接真实平台，P1 不依赖 Connector，P2 必须在合法授权商家与数据边界确认后才可启用单平台 Connector。
- 已被本目录新文档包替代的泛化文档已删除，禁止恢复或引用。
