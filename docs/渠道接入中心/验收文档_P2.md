# 渠道接入中心验收文档（P2）

状态：P2 单 Connector 验收依据，2026-07-21  
原则：每个 Connector 独立验收；一个平台通过不代表其他平台通过。

## 1. 前置条件

- 已取得真实商家的合法授权和目标平台所需资质。
- 已确认数据范围、个人信息处理、同步频率、错误联系人和停用开关。
- 业务核心标准模型已通过 P1 CSV/Excel 样例验证。
- 使用测试或经授权的最小真实数据，禁止使用未授权店铺和爬虫替代正式能力。

## 2. 单 Connector 功能验收

| 编号 | 验收项 | 通过标准 |
| --- | --- | --- |
| H-F01 | 授权与撤销 | 可完成授权、显示范围/过期状态、撤销后立即停止调用、重新授权可恢复 |
| H-F02 | 商品、SKU 与刊登状态同步 | 增量同步、外部 ID 映射、价格/库存/状态、字段来源、游标和新鲜度正确；缺字段不猜测 |
| H-F03 | 订单/物流/售后同步 | 仅同步获批范围；状态映射、去重和时间顺序正确 |
| H-F04 | 回调处理 | 已验签、去重、可追踪；重复和乱序事件不造成重复写入 |
| H-F05 | 状态可见性 | 管理员可查看连接状态、最后成功时间、失败摘要和人工重放入口 |
| H-F06 | 写操作保护 | P2 默认拒绝写操作；任何启用动作必须存在审批、动作白名单和幂等键 |
| H-F07 | 经营事实边界 | 若同步经营指标，必须具备口径、来源时间和数据新鲜度；只供业务核心生成建议，不触发平台动作 |

## 3. 隔离、安全与可靠性验收

| 编号 | 检查项 | 通过标准 |
| --- | --- | --- |
| H-Q01 | 凭据隔离 | Token 不出现在业务核心、前端、普通日志或其他 Connector 配置中 |
| H-Q02 | 故障隔离 | 模拟单 Connector 超时、限流、授权失效和宕机，业务核心及其他 Connector 保持可用 |
| H-Q03 | 重试与幂等 | 重试不重复写入；超过上限进入死信；人工重放可追溯 |
| H-Q04 | 数据最小化 | 只同步已批准字段；个人信息按规则脱敏、授权与保留 |
| H-Q05 | 停用能力 | 管理员可在不改代码的情况下暂停 Connector；暂停后不再发起平台调用 |
| H-Q06 | 审计与告警 | 授权、同步、失败、重放、停用和执行均可追溯并产生告警 |

## 4. 交付判定

所有 `H-F`、`H-Q01`、`H-Q02`、`H-Q03`、`H-Q05` 必须通过，首个 Connector 才可进入试用。任何平台新增字段、权限或写操作，均需重新执行受影响验收项并更新映射版本。
