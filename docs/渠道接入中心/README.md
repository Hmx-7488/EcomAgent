## 当前边界

- P0/P1 不启动真实 Connector，不保存任何平台 Token，不要求注册店铺。
- P2 首个 Connector 跟随首家合法授权商家的实际经营平台确定；拼多多仅为预选。
- 每个平台 Connector 独立凭据、数据库权限、队列、限流、重试、死信和告警。
- P2 只读同步；P3 才按单渠道、单动作执行已审批的发布、素材推送或受控调价，不承诺排名。
