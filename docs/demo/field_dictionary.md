# 栖纳家居字段字典

| 字段 | 必填 | 强事实 | 可用于生成 | 规则 |
| --- | --- | --- | --- | --- |
| 商品名称、类目、品牌 | 是 | 是 | 是 | 仅使用 Demo 品牌“栖纳家居” |
| SKU 名称、规格、价格、库存 | 是 | 是 | 价格仅用于展示；库存不可表述为实时 | 必须由工具读取，禁止模型补造 |
| SKU 成本 | 是 | 是 | 否 | 包括采购、包装、运费补贴、平台扣点、推广分摊、售后损耗；缺任一项时预估毛利标记待确认 |
| 预估毛利与毛利率 | 否 | 是 | 可解释，不可编造 | 必须由确定性公式根据 SKU 价格和成本实时计算，记录公式与输入快照 |
| 材质、尺寸、包装内容 | 是 | 是 | 是 | 缺失时必须提示无法确认 |
| 商品卖点、使用场景 | 是 | 否 | 是 | 不得升级为绝对化功效 |
| 发货规则、售后规则 | 是 | 是 | 仅解释规则 | 不得承诺具体订单结果 |
| 优惠、活动、物流、订单 | 否 | 是 | 否 | P0 未接数据，统一拒答或转人工 |
| 图片提示词 | 是 | 否 | 是 | 禁止真实品牌、可识别人物、平台 Logo 与促销文字 |
