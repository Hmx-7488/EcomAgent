## 1. 当前产品结论

- 产品形态：单商家、单实例、Docker 私有化部署，明确不做 SaaS 和多租户。
- 当前业务：居家收纳用品，虚构品牌“栖纳家居”，淘宝/通用货架电商表达方式。
- 当前系统：P0 业务核心；不接真实电商平台，不包含平台 SDK 或平台写操作。
- AI 边界：生成候选、事实问答和风险分级可以由 AI 辅助；图片、内容和中高风险动作
  必须人工确认。
- 双系统边界：业务核心与渠道接入中心独立设计；渠道接入从 P2 起按合法授权建设。

## 4. 当前唯一任务

**只允许对第 1 次 Qwen 请求失败进行非破坏性诊断，不允许重试。**

诊断目标：

1. 在不泄露 Key、完整 Workspace 地址、参考图 Base64 或临时 URL 的前提下，
   判断失败属于认证、Workspace/地域、模型权限、请求契约、网络、超时还是服务端错误。
2. 优先使用已有任务状态、脱敏日志、阿里云控制台调用记录和官方错误码，不发起新的
   图片生成请求。
3. 输出证据、可验证的根因判断和下一次最小 Smoke Test 方案。
4. 若现有证据不足，只能标记“根因未确认”，不得猜测或修改生产代码。

诊断完成后由产品总控决定：

- 是否批准一次最小真实 Smoke Test；
- 是否需要先修复配置或代码；
- 是否调整 C-Q05 批次方案；
- 或是否保持 BLOCKED 并暂缓。
