## 2. 官方契约冻结

- `IMAGE_GEN_MODEL` 默认 `qwen-image-2.0`；`IMAGE_GEN_OUTPUT_COUNT` 固定为 `3`，环境字符串 `3` 可正确解析，其他值启动时明确报错。
- M4.2.1 配置收口：`IMAGE_GEN_MODEL` 只允许 `qwen-image-2.0`；非空图片基址只允许 HTTPS 华北 2 Workspace 专属域名及 `/api/v1` 路径。旧公共 DashScope 图片基址给出迁移错误，HTTP、其他地域、错误模型均拒绝启动。API Key、Workspace ID 和地域必须匹配；示例不再包含旧公共地址。
- 请求使用 `/services/aigc/multimodal-generation/generation`。
- `input.messages` 只有一条 `user` 消息；`content` 依次包含经 Pillow 校验后的参考图 Base64 data URL 和一条编辑指令。
- `parameters` 固定包含 `n=3`、`size=1024*1024`、`watermark=false`。
- 解析 `output.choices[0].message.content[*].image`；空 choices、缺失 image、不足 3 张、超时、HTTP 错误、非 HTTPS URL、下载失败和无效图片均安全失败。
- HTTPS 临时 URL 继续受既有超时、响应大小、重定向与 Pillow 校验约束。三张图片全部验证并以本地不透明文件名原子保存后，任务才进入 `completed`；任一失败均不创建可审批 Asset，并删除已写入的部分文件、回滚数据库。
- `ImageGenerationTask.model_name` 保存任务实际模型快照，不再硬编码。
- Key、参考图、Base64 data URL 不写入日志或审计。
