## 2. 图片完整性修复

统一入口为 `backend/app/services/image_integrity.py`：

1. 非空、最大 10 MiB、允许 PNG/JPEG/WEBP/BMP；
2. Pillow 实际 decode、`verify()`，再重新打开并 `load()`；
3. 宽高均大于零且不超过 10,000，最大 25,000,000 像素；
4. 文件扩展名必须与实际解码格式一致；`Content-Type` 只记录为辅助信息；
5. 本地文件以 UUID 不透明文件名写入临时 `.part`，成功后原子替换；
6. 任一校验、文件保存或数据库提交失败都会回滚并清理临时/最终文件，不创建可审批 `Asset`。

Qwen HTTPS 临时 URL 仅允许 HTTPS，无凭据、localhost 或私网字面地址；下载使用连接/读取超时、最多 2 次重定向、`Content-Length` 与流式累计大小双重上限。下载字节验证后保存为本地不透明文件，临时 URL 不作为最终素材地址。
